# Ismail NFC Digital ID

A single-file responsive digital ID website for an NFC card.

## GitHub Pages

1. Upload `index.html` to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save.
6. GitHub will provide the public website URL.

Use that URL as the destination for the NFC card.

## Features

- Responsive mobile/desktop design
- Saudi-green geometric background
- Background blur
- Arabic name: اسماعيل
- Call
- WhatsApp
- Email
- Snapchat
- TikTok
- Arabic Add to Contact button
- Contact vCard generation
- Premium animations
